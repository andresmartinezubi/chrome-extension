Chrome extension to take screenshots

Context:
We are doing an audit to identify how many types of pages are in the Ubisoft ecosytem, once identified we will proceed to document them and analyse their estructure to later make an inventory of all the sections, component, functionalities used across all pages.

Tool:
We need a tool that will allow us to take full page screenshots, it can be one page, it can me from a list given by the team.


Excel file that can be provided by the team:
It will have 4 columns:
- number
- category
- product
- URL


List of functionalities for the extension:
Full page screenshots
Option to export it in PNG JPEG or PDF
Option to choose between current viewport or mobile or a custom viewport size. (since it is full page websites only ask for the witdh)
Option to add a delay before taking the screenshots to get all content if there were an animation going on.


Behavior of the extension:
The extenion before the screenshot should scroll all the way down little by little to trigger all the animation on the website. Once it reaches the bottom of the page it goes up once again and take the full page screenshot. After it should ask if I want to save it, copy to the clipboard, compress multiple files in a zip file. Also provide a preview.
